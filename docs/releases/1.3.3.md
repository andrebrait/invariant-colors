# Invariant 1.3.3

This release aligns JavaScript regular-expression colors across the IntelliJ,
Visual Studio Code, and Vim themes.

## IntelliJ

- JavaScript regex literals now inherit `DEFAULT_STRING`, their exact fallback
  declared by IntelliJ, instead of keeping Darcula's separate regex color.
- Language injection still applies more specific colors to regex operators,
  escapes, groups, and character classes.

## Other editors

Visual Studio Code already gives `string.regexp.js` the string color and applies
more specific injected-regex scopes. Vim maps `javaScriptRegexpString` to
`String`. Their color schemes are unchanged.

The JetBrains ZIP and Visual Studio Code VSIX are attached to this release. Vim
and Neovim package managers can install the `invariant-v1.3.3` tag directly.
