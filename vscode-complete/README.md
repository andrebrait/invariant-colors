# Invariant Complete

**The complete Invariant experience for Visual Studio Code.**

</div>

Invariant Complete is an extension pack containing:

- [Invariant](https://marketplace.visualstudio.com/items?itemName=andrebrait.invariant-colors) — the passive color theme.
- [Invariant Highlighter](https://marketplace.visualstudio.com/items?itemName=andrebrait.invariant-colors-highlighter) — incremental semantic enhancements.

The two extensions remain independently manageable. Disable or uninstall Invariant
Highlighter whenever you want the color theme alone.
