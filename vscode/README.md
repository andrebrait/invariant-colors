# Invariant

Invariant is a semantic dark editor theme based on Monokai. Color identifies what a symbol is; formatting shows how it is being used.

- Variables and fields use a warm neutral foreground.
- Parameters are blue and types are cyan.
- Concrete method calls are green; signature-only methods are pale blue when the language service exposes that distinction.
- Keywords and reserved names are bold pink.
- Static members are italic without changing their semantic color.
- Comments are intentionally white and prominent.

Semantic precision depends on the language extension. VS Code cannot distinguish information that its syntax grammar or semantic-token provider does not emit.

See the [project README](https://github.com/andrebrait/invariant-colors#readme) for examples, the complete palette, editor differences, and provenance.
